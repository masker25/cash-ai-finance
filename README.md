# AI-native 资金管理产品原型

这是根据 PRD V0.5 和新增「数字格式 / 版面整洁」规范制作的单页 Web 原型。

## 打开方式

直接用浏览器打开：

```text
index.html
```

如需本地服务预览，可在当前目录运行：

```text
python -m http.server 4173 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:4173/index.html
```

## 已覆盖的核心闭环

- 顶部一句话现金安全结论
- 四个核心指标
- 未来 30 天趋势图
- 关键待处理清单
- 资金变动日历
- 日期详情抽屉
- 资金事项明细表
- AI 解释 / 操作记录
- 确认调拨后重算趋势、日历、指标和 AI 记录

## 视觉与数据展示规范

- 金额统一使用「万元」并保留 1 位小数
- 大额数字使用千位分隔符
- 金额正负号明确
- 百分比保留 1 位小数
- 金额列右对齐，日期 / 状态 / 类型列固定宽度
- 主色、风险色、辅助色克制使用
- 明细进入抽屉，主页面突出现金安全判断和关键待处理事项
